# 余白データ実験（未公開）

Version 36/M、161×161の通常の白黒QRで、表URLは `https://masato-lab.pages.dev/`。表の終端以降のパディングバイトにテストデータ1,679バイトを配置し、Reed–Solomon符号を再計算した実験。

OpenCV標準QRデコーダーは元PNGから表URLを取得。別途、モジュールを復元し、鍵を使って裏の1,679バイトを復号できた。誤った鍵は拒否した。

**重要**：パディングの変更はQR規格指定の値から逸脱する。PC画面からのスマートフォン読み取りは未検証。マスクの違いと表示解像度でOpenCVの読み取り成績が大きく変わるため、現行アプリへ自動採用しない。サイズを縮小した合成画像で読み取れない例がある。

規格どおりの白黒QRとして見えることと、規格のパディングまで完全準拠することは別。
